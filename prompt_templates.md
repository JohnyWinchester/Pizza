**Task:** Создать React-компонент карточки товара для каталога пиццы.
**Context:** 
- Стек: React (Functional Components + Hooks), Tailwind CSS.
- Пропсы компонента: `id` (string), `name` (string), `price` (number), `image` (string), `onAddToCart` (function).
- Дизайн: скругленные углы (rounded-xl), тень при наведении (hover:shadow-lg), адаптивная верстка.
**Format:** 
- Полный код компонента в одном блоке `jsx`.
- Краткое пояснение (1-2 предложения) о том, как компонент обрабатывает события.
- Без лишних комментариев в коде, только JSDoc для пропсов.
