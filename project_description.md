# Описание проекта: MVP "Пицца Казань"

## 1. Описание идеи и ценности
**Идея:** Создание быстрого и интуитивно понятного веб-приложения для заказа пиццы и напитков с доставкой по Казани.  
**Ценность:** Пользователь может выбрать товары, собрать корзину и оформить заказ за 3 клика, не отвлекаясь на сложные регистрации или избыточный функционал. Прозрачность состава, цены и времени доставки.

## 2. Целевая аудитория (ЦА)
- **Основная:** Жители Казани в возрасте 18–45 лет (студенты, офисные работники, семьи).
- **Характеристики:** Ценят время, пользуются смартфонами, делают заказы спонтанно или для небольших компаний, чувствительны к удобству интерфейса и скорости загрузки.

## 3. Ключевые функции MVP (Must Have)
1. **Каталог с фильтрацией:** Отображение списка товаров (пицца, напитки) с возможностью переключения между категориями.
2. **Умная корзина:** Добавление/удаление товаров, динамический пересчет итоговой суммы.
3. **Оформление заказа:** Простая форма ввода контактных данных (имя, телефон) и выбор адреса доставки с визуализацией на Яндекс.Карте (центр: Казань).

## 4. Ограничения MVP (Out of Scope)
- Сложная кастомизация состава пиццы (добавление/удаление ингредиентов).
- Система лояльности, промокоды и история заказов.
- Онлайн-оплата (на этапе MVP заказ оформляется как "оплата при получении" или "заказ по телефону").
- Собственная система отслеживания курьера в реальном времени (только статическая карта зоны доставки).
