# ДЗ2. Шаг 1. Анализ требований к проекту

## Описание проекта
**Проект:** MVP веб-приложения для службы доставки пиццы и напитков в Казани.
**Основная цель:** Позволить пользователю выбрать товары из каталога, добавить их в корзину, оформить заказ и увидеть точку доставки на карте.

## Технологический стек
- **Frontend:** React, Vite, JavaScript (ES6+).
- **Стилизация:** Tailwind CSS (утилитарный подход, без кастомных CSS-файлов).
- **Картография:** Яндекс.Карты API.
- **Инструмент разработки:** Bolt.new (Cloud AI Agent).

## Ключевые требования к архитектуре и стилю
1. **Компонентный подход:** Интерфейс должен быть разбит на мелкие, переиспользуемые функциональные компоненты.
2. **Управление состоянием:** Использование React Hooks (`useState`, `useContext` или `useReducer` для корзины). Избегать избыточного глобального стейта.
3. **Чистота кода:** Код должен быть читаемым, с осмысленными именами переменных и функций.
4. **Адаптивность:** Mobile-first подход при верстке.
